NESTORA — REAL ESTATE WEBSITE DEMO

Files:
- index.html
- style.css
- script.js

How to preview:
Open index.html in a browser. Internet is required for remote photos and Google Fonts.

Features:
- Responsive real-estate landing page
- Property search, type and price filters
- Sorting by price
- Favourite toggle
- Property detail modal
- Contact enquiry demo form
- Mobile navigation

Important:
This is a fictional portfolio concept. Property names, locations, prices, contact details and listing information are illustrative and not real offers. The enquiry form does not send data. No backend, database, authentication, map integration or real estate transactions are connected.
